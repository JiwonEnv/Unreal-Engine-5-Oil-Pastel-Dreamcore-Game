# 꿈 수거반 (Dream Movers) — 기획 문서

> 가제. 미니 레포(R.E.P.O.) 스타일의 2~4인 협동 물리 운반 게임.

## 1. 개요

| 항목 | 내용 |
|---|---|
| 장르 | 협동 물리 운반 + 회피 (미니 레포) |
| 인원 | 1~4인 (리슨 서버, 방장이 호스트) |
| 플랫폼 | PC (Steam) |
| 엔진 | Unreal Engine 5.8 |
| 한 판 길이 | 10~15분 |
| 목적 | 환경 아트·셰이더 포트폴리오 + Tripo AI 협업 블로그 연재의 소재 프로젝트 (12장) |
| 시점 | 1인칭 (레포와 동일, 잡기 조작이 쉬움) / 로비·정산 화면에서 3인칭으로 캐릭터 노출 |
| 아트 | 드림코어 + 빈티지 골동품 + 광대 동물 인형, 오일 파스텔·색연필 포스트 프로세스 |
| 톤 | **드림코어 + 다크 동화.** 공간과 분위기는 드림코어, 캐릭터와 사건은 다크 동화 |

## 2. 컨셉

밤마다 꿈을 사들이는 **달 머리 골동품상**이 있다.
플레이어는 그에게 고용된 **광대 인형 수거반**. 누군가의 어린 시절 기억으로 지어진 꿈속 저택에 들어가 골동품을 훔쳐 나온다.
물건을 하나 가져갈 때마다 꿈은 색을 잃는다. 이 집은 이상하게 익숙하다.

웃음 포인트는 레포와 같다. 둘이 낑낑대며 크리스탈 잔을 옮기다 문틀에 박아서 깨뜨리는 순간.

한 줄 피치: *리틀 나이트메어의 저택 + 마크 라이든의 무드 + Mundaun의 연필 질감, 그 안에서 R.E.P.O.를 플레이한다.*

### 2.1 골동품 = 기억
- 골동품은 꿈꾸는 사람의 **기억 조각**이다. 훔칠수록 꿈이 빨리 바랜다. (4.4)
- 그래서 "더 가져갈까, 지금 나갈까"의 욕심과 위험의 선택이 생기고, 그 결과가 화풍 변화(`Collapse`)로 화면에 보인다.

### 2.2 톤을 나누는 이유
순수 드림코어(고요함, 외로움)는 협동 물리 게임의 소란스러움과 부딪힌다. 그래서 역할을 나눈다.
- **드림코어 담당**: 저택 공간, 색감, 조명, 벽의 문구
- **다크 동화 담당**: 광대 인형 수거반(웃음), 몬스터(위협), 달 머리 골동품상(의뢰인)

### 2.3 공간 연출 원칙
1. **익숙함 섞기**: 빅토리아풍 저택에 어린 시절 방의 요소(90년대 벽지, 무드등, 낡은 TV, 크레파스 낙서)를 섞는다.
2. **살짝 틀린 공간**: 지나치게 큰 방, 문 너머의 하늘, 실내의 잔디, 반복되는 복도.
3. **설명하지 않기**: 골동품상의 목적과 꿈꾸는 사람의 정체는 밝히지 않는다. 벽에 짧은 문구만 남긴다. (*"아직 일어나지 마"*, *"여기 와 본 적 있지?"*)
4. **밝은 불안**: 기본 톤은 과노출된 파스텔. 어둠은 대비용으로만 쓴다.

### 2.4 하지 않을 것
- **직접 전투·무기**: 몬스터는 피하거나 유인만 한다.
- **설정 설명·긴 컷신**: 세계관은 벽의 문구와 소품으로만 보여준다.
- **1챕터에서 빼는 것**: 잠긴 문과 열쇠, 업그레이드 상점 (별가루는 기록만).

## 3. 핵심 루프

```
로비(골동품점) → 꿈 입장 → 골동품 찾기 → 조심히 운반 → 탈출 지점에 납품
      ↑                                                        ↓
   정산 화면 ← 꿈이 깨기 전 탈출 (목표 금액 달성 시 성공)  ←  몬스터 회피
```

## 4. 규칙

### 4.0 이동과 웅크리기
- 걷기는 조용하다. 달리기, 점프 착지, 물건 충돌, 깨짐이 소리를 낸다. 소리는 종 달린 말만 듣는다.
- **웅크리기**: Ctrl을 누르고 있는 동안 웅크린다 (높이 60cm). 느리게 움직이고 발소리가 없다. 물건 잡기는 평소와 같다.

### 4.1 실타래 잡기
- 손에서 실을 쏴서 4m 이내 물건을 잡는다. (레포의 잡기 광선)
- 마우스 휠: 당기기 / 밀기, 단축키: 회전
- 물건마다 **무게**가 있고, 무거운 물건은 **2명 이상이 잡아야** 들린다. 잡은 사람 수만큼 힘이 합산된다.

### 4.2 내구도와 가치
- 물건이 일정 속도 이상으로 부딪히면 **금이 가고 가치가 깎인다.** (충격 세기에 비례)
- 금이 3번 가면 **깨짐** → 가치 0, 파편만 남음.
- 부딪힐 때 **소리**가 난다. 소리 크기는 몬스터(종 달린 말)가 듣는다.
- 화면에 물건 현재 가치가 떠서 금 갈 때마다 숫자가 줄어드는 게 보인다.

### 4.3 탈출과 목표 금액
- 현관 홀의 **오르골 침대**가 탈출 지점. 물건을 올려놓으면 즉시 정산 금액에 더해진다.
- 판마다 **목표 금액**이 있다. 달성하면 오르골 뚜껑이 열리고 탈출 가능.
- 목표 금액 = 맵에 놓인 골동품 전체 가치 × (20% + 인원당 10%). 1인 30%, 2인 40%, 3인 50%, 4인 60%.
- 목표 초과분은 점수(별가루)로 남는다. 처음 버전에서는 업그레이드 상점 없이 기록용.

### 4.4 꿈 안정도 (시간 제한)
- 기본 12분. 화면 구석의 괘종시계로 표시.
- 50%, 25% 시점에 **꿈이 뒤척임**: 화면이 흔들리고 방이 잠깐 기울어져 물건이 굴러간다.
- **골동품을 오르골 침대에 납품할 때마다 안정도가 깎인다: 골동품 가치 1,000당 20초.** (기억을 가져갈수록 꿈이 바램)
- 0%가 되면 꿈이 깬다. 탈출하지 못한 플레이어와 납품 못 한 물건은 모두 사라진다.
- 꿈이 깨질수록 셰이더 색이 빠지고 연필 스케치만 남는 연출. (7장 상태별 톤)
- **결정 (dream_collapse_v2)**: `Collapse`는 시간과 납품 둘 다로 줄어드는 안정도를 따른다. 곡선은 안정도 50%부터 바래기 시작해 0%에 0.75, 실패하면 1(스케치만).
- 주의: 4인이 목표(60%)만 채워도 납품으로 약 400초가 빠진다 (골동품 20종 합계 33,450 기준). 1단계 플레이에서 먼저 확인한다.

### 4.5 쓰러짐과 부활
- 몬스터에게 잡히면 인형의 솜이 터져 **솜 뭉치**가 된다. (관전 모드로 전환)
- 동료가 솜 뭉치를 잡아서 오르골 침대에 올리면 **부활**.
- 전원이 솜 뭉치가 되면 실패. 혼자 플레이할 때는 잡히는 즉시 실패.

### 4.6 랜덤 요소 (리플레이성)
매 판 아래를 섞는다. 에셋을 늘리지 않고 반복 플레이를 만들기 위함.
- **맵 구조**: 방 모듈을 판마다 다른 연결로 재배치한다 (6장). 생성기는 별도 기술 프로젝트 UE5-Procedural-Level-Generation에서 만든다.
- 일반 방의 테마 (벽·바닥 재질과 내용물)
- 골동품 배치 위치 (방마다 스폰 포인트 풀에서 선택)
- 목표 금액 (인원수에 비례, 4.3)
- 몬스터 출발 위치와 순찰 경로
- 잠긴 문과 열쇠는 1챕터에서 뺀다.

### 4.7 튜토리얼
- 튜토리얼은 없다. 조작 키 표시만 하고, 협동 게임답게 친구가 알려주게 둔다.

### 4.8 숨는 곳
- **서랍장**: 크기에 따라 1명 또는 2명이 들어간다. 안에 있으면 집사의 빛을 막는다. 들어가고 나올 때 소리가 나서 말은 듣는다. 물건을 든 채로는 못 들어간다.
- **가구 밑**: 책상·의자처럼 상판 높이 70~100cm인 가구 밑으로 웅크려서 들어간다. 문이 없어 들어가고 나오는 소리는 없다. 상판이 위에서 내려오는 촛불 빛을 가린다.

## 5. 캐릭터

### 5.1 플레이어 (4종, 같은 체형·같은 스켈레톤)
2.5등신, 둥근 몸통, 짧은 팔다리. 광대 러프 칼라 + 고깔모자 + 바느질 자국.
머리 동물과 색으로 구분한다.

| ID | 이름 | 색 테마 |
|---|---|---|
| PC_Mouse | 쥐 광대 | 빨강 + 파랑 |
| PC_Bear | 곰 광대 | 갈색 + 블루 체크 |
| PC_Frog | 개구리 광대 | 노랑 + 하늘 다이아몬드 |
| PC_Rabbit | 토끼 광대 | 연분홍 + 보라 |

### 5.2 몬스터

**촛대 집사 (Candlestick Butler)** — 시야형
- 머리 대신 불 켜진 촛대, 붉은 벨벳 연미복에 촛농이 흘러내림. 양손에 작은 손종.
- 정해진 경로를 천천히 순찰. **촛불 빛(원뿔 범위)에 닿으면** 발각.
- 발각 시 손종을 울려 종 달린 말을 부르고, 느리게 추격.
- 대응: 빛을 피해 그림자로 이동, 서랍장이나 가구 밑에 숨기 (4.8). 소리는 듣지 않는다.

**종 달린 말 (Bell Horse)** — 청각형
- 몸 전체에 종이 매달린 청동 말. 눈이 없다.
- 평소에는 한 방에 서 있다가 **큰 소리(물건 충돌, 달리기, 깨짐)가 나면** 그쪽으로 돌진.
- 움직일 때 자기 종이 울려서 접근이 들린다.
- 대응: 물건을 조심히 옮기기. 일부러 물건을 던져 유인하기.

두 몬스터가 서로 엮인다: 집사에게 들키면 → 종 → 말이 달려온다.

## 6. 맵: 꿈속 골동품 저택 (방 모듈을 판마다 재배치)

### 6.1 첫 맵 구성: 고정 방 3 + 일반 방 틀 2종 + 통로 3

| 종류 | 개수 | 내용 |
|---|---|---|
| 고정 방 | 3 | 현관 홀(시작) · 회전목마 홀(허브) · 다락 침실(끝). 전용으로 만든다 |
| 일반 방 틀 | 2종 | 크기별 틀. 같은 틀을 여러 번 쓰고, 테마를 바꿔 다른 방처럼 보이게 한다 |
| 통로 | 3 | 직선 · 꺾임 · T자 |

- 문은 방 크기에 따라 둔다. 방마다 최소 1개, 벽마다 1개 또는 2개. 안 쓰는 문 자리는 막힌 벽으로 바꿔 끼운다.
- 재배치 생성기와 재질 테마는 1단계 그레이박스 이후에 붙인다. 생성기는 별도 저장소 UE5-Procedural-Level-Generation에서 만든다.

### 6.2 고정 방

| 방 | 특징 | 주요 위협 | 드림코어 포인트 |
|---|---|---|---|
| 현관 홀 | 시작 지점, 오르골 침대(탈출) | 없음 (안전 지대) | 실내인데 천장이 하늘. 구름이 천천히 흐름 |
| 회전목마 홀 | 저택 중앙 허브. 회전목마가 돌아서 지나갈 타이밍을 봐야 함 | 종 달린 말 대기 위치 | 아무도 없는데 돌고 있음. 음정이 살짝 나간 오르골 음악이 반복 |
| 다락 침실 | 2층, 계단으로만 이동. 대형 물건을 내리는 게 어려움 | 계단 낙하 | 꿈꾸는 사람의 어린 시절 방. 가장 익숙하고 가장 섬뜩한 공간 |

### 6.3 일반 방 테마 4종

일반 방 틀 위에 테마를 씌우면 벽·바닥 재질과 방 안의 내용물(가구, 소품, 골동품 스폰, 숨는 곳)이 함께 바뀐다.

| 테마 | 특징 | 주요 위협 | 드림코어 포인트 |
|---|---|---|---|
| 찻잔 응접실 | 작은 물건이 많고 넓음. 입문용 | 집사 순찰 | 아이 키에 맞춘 거대한 가구 |
| 유리 진열실 | 좁은 통로, 비싸고 잘 깨지는 물건 집중 | 부딪히면 소리가 커짐 | 유리장 속 어린 시절 장난감. 반짝임 셰이더 쇼케이스 |
| 시계 서재 | 책장 사이 미로 | 집사 순찰 | 반복되는 리미널 통로. 시계가 모두 다른 시간 |
| 성물 예배실 | 어둡고 촛불이 많음. 고가 물건 | 집사 출발 위치 | **유일하게 어두운 방.** 밝은 저택 속 대비 |

### 6.4 공간 규격 (플레이어 기준)

저택은 사람 크기로 짓고, 그 안을 키 110cm 인형이 다닌다. 규격은 플레이어 크기 → 행동 → 환경 순서로 정했다.

| 항목 | 값 |
|---|---|
| 광대 인형 | 키 110cm · 웅크리면 60cm |
| 촛대 집사 | 키 190cm |
| 작은 문 | 150 × 250cm |
| 이중문 | 300 × 250cm |
| 한 층 높이 | 400cm |
| 벽 두께 | 20cm |
| 그리드 | 50cm |
| 숨는 가구 밑 | 상판 70~100cm |

숨기 높이 등급: 큰 가구(120cm 이상, 서서도 가려짐) · 중간 가구(70~110cm, 웅크려야 가려짐) · 가구 밑(상판 70~100cm).

벽·바닥·계단·선반은 언리얼 모델링 모드로 직접 만든다 (Tripo 크레딧 사용 안 함).

## 7. 아트와 셰이더

- **포스트 프로세스 (전체 화면)**
  - Kuwahara 필터로 유화처럼 색 뭉개기
  - 종이 질감 오버레이 + 밝기 기준 그레인 (오일 파스텔·색연필 느낌)
  - 깊이·노멀 차이로 연필 외곽선
- **반짝임**: 유리·황동 하이라이트는 별 모양 스프라이트로 따로 그린다. 필터에 뭉개지지 않게.
- **꿈 붕괴 연출**: 꿈 안정도가 낮아질수록 채도를 빼고 스케치 선만 남김.
- AI 생성 모델의 지저분한 텍스처·이음새를 셰이더가 상당 부분 가려준다.
- **컨셉 아트**: 직접 그린 스케치 → 이미지 도구로 다듬어 디자인 시트 → A포즈 레퍼런스 → Tripo 입력.

### 7.1 꿈 상태별 톤

| 꿈 안정도 | 화면 |
|---|---|
| 안정 (100~50%) | 오일 파스텔, 채도 높은 파스텔, 강한 블룸, 별 반짝임 |
| 뒤척임 (50~25%) | 색이 바래기 시작, 외곽선 흔들림 증가, 공간이 기울어짐 |
| 붕괴 직전 (25~0%) | 채도 거의 0, 종이와 연필 스케치만 남음 |

### 7.2 레퍼런스

| 작품 | 참고할 점 |
|---|---|
| Mundaun | 3D 공간 전체에 입힌 연필 질감 (붕괴 상태의 목표) |
| a-ha 〈Take On Me〉 뮤직비디오 | 실사와 스케치를 오가는 전환 |
| 마크 라이든 | 파스텔 색감, 빈티지 인형·동물·골동품 소재 |
| Superliminal | 밝은 비현실 공간 |
| 리틀 나이트메어 | 저택의 크기감, 섬뜩한 장난감 같은 몬스터 |
| 잃어버린 아이들의 도시, 미러마스크 | 꿈을 훔치는 이야기, 서커스·골동품 무드 |

## 8. 기술 구조

| 영역 | 방식 |
|---|---|
| 네트워크 | 리슨 서버. 세션은 Steam(OnlineSubsystemSteam) 또는 EOS |
| 물리 동기화 | **서버가 물리 계산 전담.** 클라이언트는 "잡는 목표 위치"만 매 프레임 전송(Unreliable RPC), 서버가 Physics Handle로 끌고 결과 위치를 복제 |
| 같이 들기 | 잡은 사람 수 × 개인 힘 ≥ 물건 무게일 때만 들림 |
| 보이스챗 | 근접 보이스 (거리 감쇠). EOS Voice 또는 Steam Voice |
| 몬스터 AI | Behavior Tree + AI Perception (집사: 시야, 말: 청각) |
| 데이터 | 골동품 1종 = Data Asset 1개 (메시, 기본 가격, 무게, 내구도, 충돌 소리, 크기 등급) |
| 맵 재배치 | 방 모듈 조립 생성기. 별도 저장소 UE5-Procedural-Level-Generation에서 플러그인으로 만들어 가져온다 |
| 재질 테마 | 방 틀(형태)과 재질 테마 데이터 에셋(벽지·바닥·몰딩 Material Instance와 값)을 분리하고, 적용기가 생성된 방에 넣는다 |
| 확장 | 저택(챕터)마다 Game Features 플러그인으로 분리 |

핵심 시스템(잡기, 내구도, 정산)은 C++, 레벨 연출과 UI는 블루프린트.

## 9. 개발 단계

**중요: 0~1단계를 끝내기 전에는 Tripo 크레딧을 쓰지 않는다.** 큐브로도 재밌는지 먼저 확인.
예외: 협업 연재 2편의 플레이어 캐릭터 4종은 협업 일정(12장)에 맞춰 먼저 만든다.

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| 0. 기술 검증 | 2인 접속 + 실타래 잡기 + 같이 들기 동기화. 셰이더 프로토타입 | 친구와 큐브를 같이 들고 옮길 때 끊김이 참을 만함 |
| 1. 그레이박스 | 고정 방 3 + 일반 방 틀 2종 + 통로 3을 공간 규격(6.4)으로 박스 제작, 판마다 재배치, 내구도·정산·꿈 안정도 루프 완성 | 큐브만으로 한 판이 처음부터 끝까지 돌아감 |
| 2. 에셋 생성 | `Tripo_Asset_List.md` 우선순위 순서대로 생성·교체 | 플레이어 4종 + 골동품 20종 적용 |
| 3. 몬스터 | AI는 0단계에 프로토타입이 있다. Tripo 모델로 교체하고 튜닝 | 두 몬스터 연계 동작 |
| 4. 폴리싱 | 사운드, UI, 정산 화면, 보이스챗, 플레이테스트 | 외부 친구 4명이 설명 없이 한 판 완주 |

## 10. 리스크

| 리스크 | 대응 |
|---|---|
| 물리 동기화가 끊기고 튐 | 0단계에서 먼저 검증. 안 되면 무거운 물건을 줄이고 "들면 손에 붙는" 방식으로 단순화 |
| 크레딧 부족 | 우선순위 A부터 생성, 장식 소품은 무료 에셋으로 대체 가능 |
| AI 모델 스타일이 제각각 | 공통 프롬프트 문구 고정, 같은 컨셉 이미지 세트로 이미지 기반 생성 |
| 폴리곤 과다로 물리 성능 저하 | 로우폴리 옵션 사용, 충돌은 단순 콜리전(박스·캡슐)으로 |
| Tripo 제작물의 상업 이용 권리 미확인 | 협업 측에 확인 요청. 계약서(발주서)로 확정되기 전에는 출시 결정 보류 |
| 협업 일정과 0~1단계 순서 충돌 | 캐릭터 4종만 예외로 먼저 생성 (9장) |
| 종 달린 말(사족) 자동 리깅이 안 맞음 | 정적 메시 + 다리만 간단히 애니메이션, 또는 종만 흔들리게 |

## 11. 확장 로드맵 (챕터)

새 챕터 = 새 저택 1채 + 골동품 10~15개 + 몬스터 1종 + 규칙 하나.

| 챕터 | 테마 | 새 규칙 |
|---|---|---|
| 1 | 골동품 저택 | 기본 |
| 2 | 서커스 천막 | 회전 스포트라이트가 집사 시야 역할 |
| 3 | 고딕 성당 (`UE5_GothicChapel` 재활용) | 종탑 종이 주기적으로 울려 소리를 덮어줌 |
| 4 | 달빛 놀이공원 | 야외, 회전목마·관람차 이동 발판 |

확장 시 업그레이드 상점(실 길이, 힘, 체력)과 판 연속 진행(목표 금액 상승)을 추가한다.
